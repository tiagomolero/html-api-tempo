# ⛅ HTML API Tempo

Este projeto é uma aplicação web simples que consome a **API OpenWeatherMap** para exibir as informações climáticas atuais de uma cidade inserida pelo usuário.

## 📌 Objetivo

O objetivo principal do projeto é demonstrar como utilizar **HTML**, **JavaScript** e **CSS** para consumir uma API externa e atualizar dinamicamente a interface com os dados recebidos.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** – Estruturação da página
* **CSS3** – Estilização do layout
* **JavaScript (Vanilla)** – Lógica de consumo da API e manipulação do DOM
* **OpenWeatherMap API** – Fonte dos dados climáticos

## 💪 Como usar

1. Clone o repositório:

```bash
git clone https://github.com/tiagomolero/html-api-tempo.git
```

2. Acesse a pasta:

```bash
cd html-api-tempo
```

3. Abra o arquivo `index.html` no navegador.

---

## 🔑 Como obter sua chave da API

1. Acesse [https://openweathermap.org/api](https://openweathermap.org/api)
2. Crie uma conta e gere sua chave de API gratuita.
3. No arquivo `script.js`, substitua:

```js
const apiKey = "SUA_CHAVE_AQUI";
```
